## Maintenance

The catalog in app/feature/explore/_components/shared-plans/plan-cover.data.ts matches exact normalized destination/country pairs and known public landmark names. It covers the 31 currently listed plans (Taipei and Taipei City share a photo). Do not use an unrelated city photograph for an unknown destination. Add a properly attributed, checked asset for each new destination that needs guaranteed local coverage. Published images and live provider photos remain preferred when available.

Do not remove a bundled asset without updating its catalog reference and regression checks. No runtime Wikimedia request or API key is needed.
